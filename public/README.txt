Place campus images in this folder.

Required for the map background:
  ynu-campus-map.jpg   - Yunnan University Chenggong campus map image

Optional reference image (kept if present):
  ynu-route-board.jpg  - campus bus route-board photo

The dashboard loads /ynu-campus-map.jpg as the map background. If the file
is missing, the map card shows a clean placeholder with a short note and the
route overlay still works. Add the JPG file here and reload to see the real
campus map behind the routes.
